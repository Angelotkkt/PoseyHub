# Simply Hub

YouTube, Discord, Spotify, Netflix, Disney+, HBO Max, Prime Video et tous tes jeux dans une seule appli Windows, par **PoseyDevs**.

**Télécharger : https://angelotkkt.github.io/PoseyHub/**

Ce dépôt fabrique l'appli tout seul : à chaque modification de `src/`, `assets/` ou `package.json`,
GitHub construit `SimplyHub-Setup.exe` et `SimplyHub-portable.exe` sur un PC Windows et les met dans la
publication [« windows »](https://github.com/Angelotkkt/PoseyHub/releases/tag/windows).
Simply Hub y lit `latest.yml` et se met à jour tout seul, sans désinstaller.

Le site de téléchargement est `index.html` (GitHub Pages, branche `main`, dossier racine).

Pour fabriquer l'appli sur ton PC : voir [LISEZ-MOI.md](LISEZ-MOI.md).

Simply Hub est un projet perso, gratuit, sans lien avec YouTube (Google), Discord, Spotify, Netflix, Disney, HBO / Warner Bros. Discovery ou Amazon.
