Connecter Spotify à Simply Hub

Simply Hub utilise la connexion officielle de Spotify. Il faut créer une fois une « appli » gratuite sur Spotify for Developers. C'est rapide, et ça ne se fait qu'une seule fois.

1
Ouvre Spotify for Developers

Connecte-toi avec ton compte Spotify. Spotify exige un compte Premium pour créer une appli.

2
Clique sur « Create app » et remplis :

App name : Simply Hub · Description : ce que tu veux
Redirect URI : copie exactement cette adresse puis clique sur « Add » :

http://127.0.0.1:47823/callback

Dans « Which API/SDKs are you planning to use? », coche Web API et Web Playback SDK, accepte les conditions puis clique sur Save.

3
Copie le « Client ID » de ton appli ici

Tu le trouves dans la page de ton appli, en haut. Le « Client secret » n'est pas nécessaire.

Connexion à Spotify

La page de connexion officielle de Spotify va s'ouvrir dans ton navigateur.
Accepte, puis reviens ici, c'est automatique.
